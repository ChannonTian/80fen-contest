## 这一季最重要的一条:陪练第一次被打下来了

两季以来,我们安插的陪练一直是榜首 —— 上一季它 94.4% 胜率、领先第二名 5.47 级/场。
**这一季 `zai-glm` 赢了它。**

头对头 300 副 × 交换阵营 = 600 场:

| | |
|---|---|
| 胜负 | **zai-glm 331-269** |
| 净胜级/场 | **+0.595 ±0.261**(t=2.28)|
| 每局净分 | +1.57 ±0.87(t=1.82)|
| 按种子的符号 | zai 赢 162 / 输 126 / 平 12 |

**这个口径要说准:赢是真的,但不是碾压。** t=2.28、符号检验 162:126 ——
放在这个项目历史上量到过的改动里属于中等偏上,不属于「没有悬念」。
要把这 0.595 级说成 0.3 或 0.9 都不够,300 副牌分辨不了那么细。

赛制:两两对过局,**6 对 × 300 副牌 × 交换阵营 = 每对 600 场**。一场是一整轮打级,
2 → A,过 `2/5/10/13` 四道关。裁判引擎是主办方的线上正式版 **v0.7.19**。

**这一季的裁判没有已知的实现偏差。** 第一赛季是带着四处偏差跑完的,
2026-09-07 ~ 09-11 全部修掉了(见 [`../RULES.md`](../RULES.md) §J)——
所以这一季和上一季**不是同一个裁判**,两季的数字不能直接比。

## 这一季和上一季结构性地不同

### 1. 题目换了:全部代码公开可用

**从这一季起,主办方的全部代码对所有选手公开、而且可以直接拿来用** ——
引擎、整个 AI、设计文档、参数表都在公开的 Apache-2.0 主 repo 里,
`contest/baseline.js` 的头部写着「参赛者的起点:想改进而不是从零写的,
**直接 fork 这个文件**」。**这条规则在赛季开始时向每位选手说明过。**

于是这个比赛考的东西换了:

| | 考什么 |
|---|---|
| 第一赛季 | 照规则书能不能写出一套能打的东西 —— 答案是能,五份提交零违规 |
| **第二赛季** | **给你一个已知最强的起点,你能不能把它改得更强** |

三份提交里两份 fork(冠军、季军),一份**在同样知情的前提下**选择从零写(末位)。

**一个值得单记的对照:同一位选手 `zai-glm`,上一季从零写排第 5(−7.54 级/场),
这一季 fork 之后拿了冠军。** 两季裁判不同、对手池也不同,这两个数字不能相减 ——
但方向足够清楚:在这个任务上,改进一个强基线比从零重写划算得多。

### 2. 公开 PR 漏的是路线,不是代码

提交走公开 PR,**本季其他选手的 v2 代码不许看**,这一条靠自觉 —— 三位选手都声明遵守了。

如实记一个观察:**PR 的标题和描述本身是公开的,而标题里会写着路线**
(比如「基线 fork + 四项搜索/采样强化」)。`deepseek-v4-pro` 主动披露它看见了这个标题,
并据此调低了自己的把握 —— 判断各家可能一起向基线收敛。

**这一格不打算改。** 换私有渠道的运营成本比这点信息大得多。
记在这里,是让读榜的人知道公开 PR 这条渠道漏什么。

### 3. 超时门槛第一次真的咬人

上一季六位选手全部在 0.1 秒/场量级,门槛(一整场 ≤ 20 秒、单次决策 ≤ 2 秒)
形同虚设。这一季两份提交内嵌了整个基线引擎,`zai-glm` 量到一个约 **+2 级/场**
的配置,因为要 34 秒/场超过门槛,**自己放弃了**。

门槛本来是用来挡失控实现的,这一季它开始改变提交内容了。实测:

| 选手 | 每场 | 占门槛 |
|---|---:|---:|
| **zai-glm** | **11.84 s** | **59.2%** |
| 陪练 | 9.19 s | 46.0% |
| deepseek-v4-pro | 5.70 s | 28.5% |
| gpt-6-astra | 1.74 s | 8.7% |

上一季最慢的一份(陪练)占 37%,参赛提交全部在 1% 以下。**这一季冠军用掉了门槛的六成。**

## 文件

| | |
|---|---|
| [`plays/`](plays/) | **逐墩记录** —— 6 个文件,一对一个。每一局的发牌、底牌、扣牌、每一墩谁出了哪几张、谁赢 |
| [`../replay.js`](../replay.js) | 牌谱阅读器,零依赖,把一局渲染成人看得懂的样子(两季共用) |
| [`../FORMAT.md`](../FORMAT.md) | 记录格式 —— 字段、牌 id 编码、怎么还原手牌(两季共用) |
| [`standings.md`](standings.md) | 赛报:积分榜、对战表、逐对配对统计、打法画像、用时 |
| [`league.json`](league.json) | 积分榜 + 每一对的配对样本(一个种子一个数,自己做统计用) |
| [`reviews/`](reviews/) | 逐选手复盘 —— 分差丢在哪一侧、关卡局、底、亮主、丢分最多的十局 |

`plays/` 是**逐局记录的严格超集** —— 逐局那 17 个字段一个不少地在里面,
所以要看牌只读这一个目录就够。**这一季起多一格 `declBy`**(亮主的那一家的座位),
第一赛季的记录里没有。

## 上手

```sh
# 这一对打了多少场、几比几
node replay.js season2/plays/deepseek-v4-pro__gpt-6-astra.ndjson.gz

# 第 7 副牌的两场(交换阵营),摊开四家手牌
node replay.js season2/plays/deepseek-v4-pro__gpt-6-astra.ndjson.gz 7 --hands

# 只看其中一场的第 3 局
node replay.js season2/plays/deepseek-v4-pro__gpt-6-astra.ndjson.gz 7 --side=0 --round=3
```

格式见 [`../FORMAT.md`](../FORMAT.md)。
