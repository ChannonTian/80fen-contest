## 跑分器口径 (血泪教训)

- `round` (无庄局): 亮主=抢庄。**别用它测亮主策略**。
- `decl` (庄定局, 同牌两队各当一遍庄, 值=闲家分差): 测庄家侧。**线性分值, 看不到"档次灾难"**(0/40/80 分档与抠底×2 的跳变), 与 match 打架时它可能是错的。
- `match` (完整整场, 造反开): 权威口径, 但造反使发牌流分叉, 配对有噪声。
- `matchnr` (完整整场, 禁造反): 发牌流全程对齐, 配对干净; 与 match 一起用。
- **结论: 采纳改动前必须 match/matchnr 口径显著; decl 只是辅助线索。**

## 基线链 (match/matchnr 口径, 每步 vs 上一版)

- v0: 初版启发式 (亮主16/19 + 扣底埋分 + 领出/跟牌启发式)。
- v1 = v0 + 跟牌喂分修复 (对手赢墩垫非分; 不反超队友): match +0.35胜/+3.2级。
- v2 = v1 + 领出断门规避 (闲家断门的花色不领, 队友断门+1.2): match +0.23胜/+1.8级。
- v3 = v2 + 自动甩牌 (领出组件=本门最小组件时整门甩出, 零风险): match +0.31胜/+3.3级。
- v4 = v3 + 扣底随强弱 (弱庄少埋分 bump30, 强庄多埋分 drop10): match +1.1级 (t≈2.2~2.7)。
- **v5 = v4 + 首攻 A 降权 (1.1→0.5, 保留 A 当控制牌)**: matchnr +0.18胜 (t=2.7) / +2.2级 (t=3.0), 交叉种子复核一致。
- 累计 v0→v5: 每对场 +~1.1 胜场、+~11.6 级。参照: 对 dumb(合法无脑) 30/30 全胜 +22级; 自对弈庄家侧闲家墩分 82→71, 被上台 62%→47%。
