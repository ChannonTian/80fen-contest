```
submissions/
  zhang-san/
    index.js      ← 入口,必须有
    engine.js     ← 你自己照 RULES.md 写的规则实现
    ...
```

接口、罚分、赛制见[上一层的 README](../README.md),模板在 [`../example/`](../example/)。

**别改 `submissions/` 以外的任何文件** —— 改了的 PR 会被退回。
