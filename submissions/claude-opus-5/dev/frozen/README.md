# dev/frozen —— 计时标尺专用,**永不更新**

这里是 `engine.js` / `moves.js` 在提交版 `ede10e6`(第一次合并进 main 的版本)
的快照。

为什么需要它:`dev/bots.js` 里的参照选手原本 `require('../moves.js')`,也就是
**我自己的**着法生成器。于是我每优化一次共享代码,参照选手也跟着变快 —— 而
同样的绝对省时,对 7µs 的 greedy 是 14%、对 24µs 的我只有 4%,**比值反而变差**。
我一度以为几处优化"量不出来",其实是标尺自己也在动。

真正的基准选手用的是主办方自己的引擎,不会因为我优化而变快。所以计时用的
标尺必须冻住。**不要更新这个目录**,否则时间预算的历史读数会全部失去可比性。
