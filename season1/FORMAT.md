# 牌谱格式

第一赛季的全部对局都在 `plays/` 里,**一对选手一个文件**,gzip 压过的 NDJSON —— 一行一场,
每行是一个完整的 JSON 对象。文件名是 `<选手A>__<选手B>.ndjson.gz`。

```sh
zcat plays/claude-opus-5__kimi-k3.ndjson.gz | head -1 | jq .
```

不想自己解的话,`replay.js` 会把一局渲染成人看得懂的牌谱:

```sh
node season1/replay.js plays/claude-opus-5__kimi-k3.ndjson.gz          # 这一对打了多少场
node season1/replay.js plays/claude-opus-5__kimi-k3.ndjson.gz 7 --hands # 第 7 副,摊开手牌
```

---

## 一行 = 一场

```jsonc
{
  "a": "claude-opus-5",   // 这一对的两名选手,和文件名同序
  "b": "kimi-k3",
  "seed": 7,              // 第几副牌。同一个 seed 有两行,aTeam 分别是 0 和 1
  "aTeam": 0,             // a 这一场坐哪一队:0 = 座位 0/2,1 = 座位 1/3
  "winner": "a",          // "a" | "b" | null(打满 200 局仍未分出胜负)
  "levels": [16, 10],     // 终局级数,[a 的, b 的]
  "rounds": [ /* 一局一条,见下 */ ]
}
```

**每副牌打两场,阵营对调。** 交换阵营只消得掉第一局的牌运 —— 之后庄家轮换按输赢分叉,
两场的牌就走散了。所以同一个 `seed` 的两场不是互为镜像,得当两场看。

## 一条 = 一局

前 17 个字段和 `rounds.ndjson.gz`(逐局记录)里的**完全一样**,后 5 个是这里才有的。
换句话说 `plays/` 是逐局记录的严格超集,只读这一个文件就够。

| 字段 | 含义 |
|---|---|
| `no` | 这一场里的第几局,从 1 起 |
| `declSeat` / `declTeam` | 庄家的座位 / 队(`declSeat % 2`) |
| `trump` | 主花色 `"S"`/`"H"`/`"D"`/`"C"`,无主是 `null` |
| `trumpRank` | 主级数(2..14),这一局打几 |
| `declBy` | **亮主的那一家的座位**(没人亮主是 `-1`)。庄定盘里庄家恒不变,所以主色有相当一部分是闲家定的 —— 它和 `declSeat`(坐庄的那家)不是一回事。**第二赛季起才有;第一赛季的记录里没有这一格**,当时裁判没往外给 |
| `declStrength` | 亮主链上的强度:`1` 单张级数牌、`2` 一对级数牌、`3` 小王对、`4` 大王对。王对不属于任何花色,所以 `declStrength >= 3` 的局 `trump` 一定是 `null`(全季 1045 局无主,468 + 577,一局不差) |
| `rawTotal` | 闲家**在墩上**拿到的分,判罚之前 |
| `total` | 闲家的**最终**得分(见下面的三步) |
| `penalty` | `[队0 被罚, 队1 被罚]`,单位是分 |
| `defendersWin` | 闲家是否上台(`total >= 80`) |
| `defLevelsUp` | 闲家上台时升几级;守住时没有这个字段 |
| `defWonLast` | 末墩是不是闲家赢的(抠底的前提) |
| `tricks` | 这一局打了多少墩 |
| `kittyPts` / `mult` | 底牌里的分 / 抠底倍数 |
| `before` / `after` | 这一局前后两队的级数 `[队0, 队1]` |
| `redeals` | 造反重发了几次 |
| **`seed`** | 这一局的**发牌种子**(和场级的 `seed` 不是一回事) |
| **`first`** | 切牌定先的结果:哪个座位先拿牌 |
| **`kitty`** | 底牌 8 张的牌 id |
| **`buried`** | 庄家扣下去的 8 张 |
| **`plays`** | 每一墩,见下 |

闲家的最终得分是**三步**来的,三步的中间值记录里都有 —— `total != rawTotal`
不一定是罚了分,多半只是抠了底:

```
rawTotal(墩上分)
  → 加上对方的罚分、减去自己的罚分,夹回 [0, 200]
  → 末墩是闲家赢的话,再加 kittyPts × mult
  = total
```

## 一墩

```jsonc
"plays": [
  { "w": 1, "p": [[80,26], [31,89], [88,34], [86,81]] },
  ...
]
```

* `p` 是四家出的牌,**按出牌顺序**排 —— `p[0]` 就是领出方。
* `w` 是这一墩谁赢(座位号)。
* **领出方不记**,因为算得出来:第一墩是庄家 `declSeat`,之后每一墩是上一墩的 `w`。

```js
let lead = r.declSeat;
for (const t of r.plays) { /* t.p[k] 是座位 (lead+k)%4 出的牌 */ lead = t.w; }
```

## 牌的 id

两副牌,id `0..107`。低 54 张是第一副、高 54 张是第二副,**同一张牌的两份 id 相差 54**
(所以 `id % 54` 相等就是同一张牌 —— 判对子靠这个)。每副里:

| `id % 54` | |
|---|---|
| `0..12` | ♠2 ♠3 … ♠A |
| `13..25` | ♥2 … ♥A |
| `26..38` | ♦2 … ♦A |
| `39..51` | ♣2 … ♣A |
| `52` | 小王 |
| `53` | 大王 |

```js
function card(id){
  const d = id % 54;
  if (d === 52) return {suit:'X', rank:15};      // 小王
  if (d === 53) return {suit:'X', rank:16};      // 大王
  return {suit:'SHDC'[Math.floor(d/13)], rank: 2 + d % 13};   // rank 11=J 12=Q 13=K 14=A
}
```

分:`rank === 5` 是 5 分,`rank === 10` 和 `rank === 13`(K)各 10 分。一局 200 分。

## 手牌不记,但还原得出来

每家出掉的 25 张**就是**它发到手的 25 张。庄家那一家多一步:它出的 25 张
加上扣掉的 8 张、再去掉底牌的 8 张,就是发到它手上的 25 张。

```js
const kitty = new Set(r.kitty);
declHand = [...playedBy(r.declSeat), ...r.buried].filter(id => !kitty.has(id));
```

四家还原出来的手牌加上底牌那 8 张,应当恰好是一副 108 张 ——
`replay.js` 每渲染一局就验一次这个等式。

## 复现

决策路径上没有 `Math.random`、没有 `Date.now`,同一个种子必然发同一副牌、
走同一条线。这一季 258722 局的逐局记录,是拿归档里那份和重跑的**逐字节比对**过的。

**但要用当时那个裁判。** 这份牌谱是在 2026-09-07 / 09-08 修掉三处已知偏差(见
[`../RULES.md`](../RULES.md) §J)**之前**的裁判上跑的 —— 只有这样才和归档对得上,
也才是第一赛季真正打出来的那些牌。换成修好的裁判,同一个种子会在那 0.0033% 的
跟牌局面上分叉,之后整场就走散了。牌谱记的是**当时发生了什么**。
